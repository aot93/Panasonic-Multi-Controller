# Sample slides

Reference/template images for vision-based name verification
(`docs/vision-name-verification-plan.md`) — content meant to be displayed on
a projector's input so the "Verify Name" check has legible text to read.

Per the plan's limitation #2: the check can only work if the projector's
displayed content contains the device's configured name as legible text.
Drop sample or template slide images here (e.g. exported from whatever
signage/slide tool is used) — large, high-contrast, sans-serif text works
best for OCR.

Not wired into the app itself — this is reference material for producing
signage, not an asset the app loads.
